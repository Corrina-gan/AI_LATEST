A Streamlit prototype that recommends movies from the MovieLens `ml-latest-small` dataset. It compares three approaches on the same 80/20 per-user train/test split: content-based (TF-IDF), collaborative filtering (user-kNN, item-kNN, SVD), and a hybrid that blends content with SVD. The app reports RMSE plus liked / not-liked classification (precision, recall, F1, accuracy).

---

## Main prototype functions

- **Hybrid** — Top-N list; search a title for a predicted 0.5–5 rating; content vs SVD blend-weight charts and alpha sweep; evaluation
- **Content-based** — Top-N from TF-IDF user profiles; optional MMR diversity; more-like-this genre; genre profile; evaluation
- **Collaborative** — User-based kNN, item-based kNN (cosine or Pearson), and matrix factorization (TruncatedSVD); optional genre filter; neighbourhood *k*; evaluation
- **Model Comparison** — Side-by-side RMSE / precision / recall / F1 / accuracy for the three algorithms
- **Data Visualization** — EDA charts on the cleaned ratings, movies, and tags
- **Data Explorer** — Browse cleaned movies, ratings, links, and posters (optional)

Each recommender page also has its own features.

## Dataset and trained-model setup

### Dataset files

The raw MovieLens CSV files are already included. You do **not** need to download MovieLens unless the `dataset/` folder is missing.

```
dataset/movies.csv
dataset/ratings.csv
dataset/tags.csv
dataset/links.csv

```

If those four CSVs are missing, download [ml-latest-small.zip](https://files.grouplens.org/datasets/movielens/ml-latest-small.zip), extract it, and copy `movies.csv`, `ratings.csv`, `tags.csv`, and `links.csv` into `dataset/`. The filenames must match exactly.

### Cleaned data

The cleaned files are already included in `processed/`. They were generated by `data_preprocessing.py`.

```
processed/movies_clean.csv
processed/ratings_clean.csv
processed/tags_clean.csv
processed/links_clean.csv
processed/movies_content.csv
processed/posters.csv
```

`processed/posters.csv` is optional. It was generated once with `fetch_posters.py` (TMDB). The app does not call TMDB while running.

If `processed/` is already present, **skip preprocessing**. To rebuild from `dataset/`:

```bash
py data_preprocessing.py --output-dir processed
```

That writes the cleaned CSVs listed above (except posters). After cleaning: about **602 users**, **3,643 movies**. Rebuilding `processed/` changes the data signature, so the app will retrain and overwrite `trained_model/`.

### Trained models

Trained models are already included. **No download is required.**

trained_model/model_download_link.txt

Do **not** retrain unless the joblib files are missing or `processed/` was rebuilt. The raw dataset, processed data, and trained models are all in the submission.

## TMDB API key (optional — posters only)

Do not submit a real API key. `.env` is gitignored. The recommenders, evaluation, and charts do **not** use TMDB.

A free [TMDB](https://www.themoviedb.org/) v3 API key is used only by `fetch_posters.py` to fill `processed/posters.csv`. The Streamlit app never reads this key and never calls TMDB at runtime; it only reads poster URLs from that CSV.

To get a key (optional): register at themoviedb.org → account settings → API. In the project root, copy `.env.example` to `.env` and replace the placeholder:

```
TMDB_API_KEY=your_tmdb_api_key_here
```

Or set it for one PowerShell session:

```powershell
$env:TMDB_API_KEY = "your_key_here"
py fetch_posters.py
```

Posters are saved to `processed/posters.csv`. The app still runs without them (cards have no cover art).

## Running the prototype

From the project root:

```bash
py -m streamlit run app.py
```

1. Streamlit opens (or prints) `http://localhost:8501`. Open it in a browser if needed.
2. If `trained_model/` is present, the app **loads** the joblib files. If they are missing, it trains (a few minutes) and saves them.
3. Wait until the sidebar **User ID** dropdown appears.
4. Pick a User ID and how many recommendations to show, then use the pages.

Optional CLI (same data, prints tables in the terminal):

```powershell
py content_based.py --user-id 1 --top-n 10
py collaborative_filtering.py --user-id 1 --top-n 10
py hybrid.py --user-id 1 --top-n 10 --no-tune-alpha --alpha 0.05
py data_visualization.py
```

`hybrid.py` tunes alpha on F1 by default (several minutes). The command above skips tuning and uses alpha `0.05`.

## Known limitations

- **Catalogue size** — After cleaning: about 602 users and 3,643 movies. New users cannot be added in the UI; pick an existing User ID.
- **Fixed SVD factors** — Hybrid SVD uses 20 latent factors (fixed). Only alpha is grid-searched using F1; other hyperparameters are not tuned.
- **Different content profiles** — Hybrid’s content profile is an unweighted mean of TF-IDF vectors (star rating is not a profile weight). The standalone content-based page uses a rating-weighted profile.
- **Evaluation cutoff** — Liked / not-liked uses actual rating ≥ 4.0. The predicted-liked cutoff is chosen to maximise F1 and is **not** used for Top-N ranking.
- **Posters** — Optional. The app works without them. Use existing `processed/posters.csv` or fetch with a TMDB key. The browser needs Internet to load image URLs.

## Troubleshooting

- **Terminal is not in the project root** — Run `dir` (Windows) or `ls` (macOS/Linux). You should see `app.py`. Or open the folder that contains `app.py` in File Explorer and launch PowerShell from the address bar.
- **FileNotFoundError / “run data_preprocessing.py first”** — From the project root: `py data_preprocessing.py --output-dir processed`. Confirm `processed\movies_clean.csv` exists.
- **python / py not found** — Install Python 3.13. On Windows use `py`. On macOS/Linux use `python3`.
- **Old recommendations after code/data changes** — Sidebar **Clear model cache**, or stop Streamlit with Ctrl+C and start it again.
- **Port 8501 already in use** — Stop the previous Streamlit process with Ctrl+C, or use another port "py -m streamlit run app.py --server.port <any_port_number> , for example: `py -m streamlit run app.py --server.port 8502`
- **TMDB_API_KEY is not set** — Only happens if you run `fetch_posters.py`. The app does not need the key. Set it in `.env` or `$env:TMDB_API_KEY` if you want posters.
- **ModuleNotFoundError** — For this project only: activate `.venv`, then `py -m pip install -r requirements.txt`. For a global install: skip `.venv` and run `py -m pip install -r requirements.txt`.
